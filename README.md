# Air University Website

A responsive frontend university website built using HTML, CSS, and Bootstrap.  
This project is a static website design for Air University that showcases different sections such as academics, admissions, campus life, health care, athletics, research, and upcoming events.

---

## Features

- Responsive university website design
- Modern homepage layout
- Navigation bar with search option
- Hero section
- Academics section
- Campus news cards
- Research statistics section
- Upcoming events section
- Health care section
- Campus life section
- Athletics section
- Admission section
- Footer with social media icons and navigation links

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 4

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/air-university-website.git
```

2. Open the project folder

```bash
cd air-university-website
```

3. Run the project

Open `index.html` in your browser.
